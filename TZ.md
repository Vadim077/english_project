AI Language Trainer
AI Language Trainer — это интерактивная веб-платформа для практики разговорного английского языка с использованием мощностей современной языковой модели Llama 3.3.

🌟 О проекте
Проект решает проблему "языкового барьера", предоставляя пользователю безопасную и бесконечно гибкую среду для тренировки. В отличие от большинства приложений с фиксированными уроками, здесь вы сами создаете контекст.

Интерфейс приложения полностью на русском языке, но погружение в языковую среду максимально строгое — после запуска сценария ИИ общается исключительно на английском.

⚡ Ключевые возможности:
Полная свобода сценариев: Введите любую ситуацию текстом на русском языке (например: "Я пытаюсь вернуть бракованный товар в магазине в Лондоне"), и ИИ мгновенно подстроится под эту роль.
Умная архитектура диалога (JSON): ИИ одновременно генерирует ответную реплику и проводит анализ вашей грамматики. Результаты выводятся в отдельном окне (даже если ошибок нет, система подтвердит: "Всё верно").

Голосовой движок (Web Speech API):
ИИ озвучивает свои сообщения автоматически.
Вы отвечаете голосом в режиме рации (Push-to-Talk). Запись идет, пока кнопка зажата. Есть возможность отменить запись и наговорить текст заново.

Адаптация под уровень: Выбирайте свой уровень (от A1 до C2) — ИИ будет использовать соответствующую лексику и грамматику.

Оптимизированная память: ИИ удерживает в контексте ровно 7 последних реплик, что обеспечивает идеальный баланс между адекватностью диалога и скоростью ответа.

🛠 Технологический стек
Frontend: React + TypeScript + Vite (быстрый и типизированный интерфейс).

Backend: FastAPI (Python) — современный и высокопроизводительный сервер.

AI: NVIDIA NIM API (Llama-3.3-70b-instruct). Форматирование ответов в строгом JSON.

Voice: Браузерное Web Speech API (не требует платных ключей).

База данных: PostgreSQL — хранение профилей пользователей, реализация полноценной системы регистрации и авторизации.

Этапы разработки
[ ] Настройка окружения: Инициализация БД PostgreSQL и реализация системы регистрации/авторизации пользователей.
[ ] Бэкенд & AI: Подключение NVIDIA Llama 3.3 API, настройка системных промптов для генерации ответов в JSON (реплика + разбор ошибок).
[ ] Фронтенд (UI/UX): Создание экрана ввода стартового сценария и интерфейса чата (с боковой панелью для грамматики).
[ ] Интеграция голоса: Подключение Web Speech API (Push-to-Talk, кнопка отмены записи, автоозвучка ответов ИИ).
[ ] Сборка и тестирование: Оптимизация контекстного окна (ограничение в 7 сообщений) и финальная отладка.

Подробные этапы работы:
Этап 1: Инициализация проекта и База Данных (Настройка фундамента)
На этом этапе мы готовим почву. Никакого ИИ пока нет, только базовая инфраструктура.
[y] 1.1. Создание структуры папок: Инициализировать репозиторий Git, создать папки frontend и backend.
[y] 1.2. Настройка БД (PostgreSQL): Установить PostgreSQL, создать пустую базу данных (например, lingua_db).
[y] 1.3. Скелет Бэкенда (FastAPI): Развернуть базовое приложение FastAPI, настроить CORS (чтобы фронтенд мог обращаться к серверу).
[y] 1.4. Проектирование таблиц (ORM): Написать модели базы данных (например, с использованием SQLAlchemy):
Таблица Users (id, email, hashed_password, level).
Таблица Scenarios (id, user_id, topic, created_at).
Таблица Messages (id, scenario_id, role (user/ai), text, corrections).
[y] 1.5. API Авторизации: Написать эндпоинты регистрации (/register) и логина (/login) с выдачей JWT-токена.

Этап 2: Базовый Фронтенд и Авторизация
Делаем так, чтобы пользователь мог зайти в систему.
[ ] 2.1. Скелет Фронтенда (Vite + React): Установить React, TypeScript, настроить Tailwind CSS для стилей.
[ ] 2.2. Роутинг: Настроить React Router (страницы: Логин, Регистрация, Главная/Настройка сценария, Чат).
[ ] 2.3. Формы входа: Сверстать формы авторизации и регистрации.
[ ] 2.4. Интеграция Auth: Связать формы входа с бэкендом, настроить сохранение JWT-токена в localStorage.

Этап 3: Ядро ИИ (Backend Logic)
Самый "вкусный" этап. Учим сервер общаться с Llama 3.3.
[ ] 3.1. Подключение NVIDIA NIM: Зарегистрироваться, получить API-ключ, написать функцию отправки запроса к Llama 3.3.
[ ] 3.2. Системный Промпт (System Prompt): Написать мощную инструкцию для ИИ: "Ты в роли [сценарий]. Уровень юзера [A1-C2]. Общайся только на английском. Отвечай в формате JSON...".
[ ] 3.3. Логика ответа (JSON): Настроить бэкенд так, чтобы он парсил ответ ИИ, разделяя его на две переменные: reply (сам текст) и corrections (ошибки или статус "Всё верно").
[ ] 3.4. Управление контекстом (Память): Написать функцию, которая перед отправкой запроса к ИИ достает из БД ровно 7 последних сообщений текущего диалога, чтобы Llama понимала контекст беседы.
[ ] 3.5. API Чата: Создать эндпоинт /api/chat/send, который принимает сообщение юзера, сохраняет в БД, дергает ИИ, сохраняет ответ ИИ в БД и возвращает его на фронтенд.

Этап 4: Интерфейс Чата и Сценариев (Frontend UI)
Рисуем то, что будет видеть пользователь.
[ ] 4.1. Экран старта: Поле ввода на русском ("Опишите ситуацию"), выпадающий список (выбор уровня A1-C2), кнопка "Начать".
[ ] 4.2. Верстка Чата: Сверстать основное окно переписки (пузыри сообщений как в Telegram).
[ ] 4.3. Боковая панель ошибок: Сверстать панель справа. Сделать так, чтобы при клике на любое сообщение в чате, в панели появлялся его разбор (поле corrections из БД).
[ ] 4.4. Интеграция Чата с API: Настроить отправку текста с фронтенда на эндпоинт /api/chat/send и отображение ответа. На этом этапе чат полностью работает, но пока только текстом.

Этап 5: Голосовое погружение (Web Speech API)
Превращаем текстовый чат в голосовой тренажер.
[ ] 5.1. Кнопка Push-to-Talk (UI): Создать большую кнопку микрофона с анимацией удержания. Рядом добавить маленькую кнопку "Отмена" (сбросить текущую запись).
[ ] 5.2. Speech-to-Text (Пользователь говорит): Подключить SpeechRecognition из Web Speech API. Настроить: при зажатии мыши начинаем слушать (на английском языке!), при отпускании — переводим в текст, показываем юзеру и отправляем на бэкенд.
[ ] 5.3. Text-to-Speech (ИИ отвечает): Подключить speechSynthesis. Как только с бэкенда приходит ответ от ИИ (поле reply), браузер автоматически зачитывает его вслух английским голосом.

Этап 6: Тестирование, Дебаг и Защита
Готовим проект к показу преподавателю.
[ ] 6.1. Обработка ошибок: Добавить лоадеры (крутилки), пока ИИ думает. Выводить красивые сообщения, если отвалился интернет или API NVIDIA недоступно.
[ ] 6.2. Тестирование лимитов: Проверить, как ведет себя база данных и контекстное окно, когда сообщений становится больше 20.
[ ] 6.3. Финальный прогон: Зарегистрировать нового пользователя, пройти полный цикл создания сценария и голосового общения.

Проект разрабатывается в учебных целях для демонстрации навыков работы с базами данных, современными AI-технологиями и построения Fullstack-приложений.
