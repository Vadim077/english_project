# ТЗ: AI Language Trainer (Ultra-Light Version)

**AI Language Trainer** — это компактный веб-тренажер для практики разговорного английского языка. Проект ориентирован на максимальную простоту архитектуры, легкость демонстрации и понимания кода.

## 🌟 Концепция
Пользователь выбирает сценарий общения (например, "В магазине") и уровень владения языком. После этого он ведет диалог с ИИ, который имитирует собеседника, озвучивает свои реплики и дает краткую обратную связь по грамматике пользователя.

## ⚡ Ключевые возможности
1.  **Сценарии на лету:** Пользователь вводит любую ситуацию на русском языке, ИИ мгновенно входит в роль.
2.  **Голосовой движок (Web Speech API):** 
    *   Автоматическая озвучка ответов ИИ.
    *   Голосовой ввод сообщений (STT) через браузер.
3.  **Контекстная память:** ИИ помнит до 10 последних реплик в рамках текущей сессии (хранится в оперативной памяти).
4.  **Разбор ошибок:** В каждом ответе ИИ анализирует последнюю реплику пользователя и указывает на ошибки (в формате JSON).
5.  **Адаптивность:** Настройка уровня сложности (A1-C2).

## 🛠 Технологический стек
*   **Backend:** FastAPI (один файл `main.py`).
*   **AI:** NVIDIA NIM API (Llama-3.3-70b-instruct).
*   **Frontend:** Vanilla HTML + JavaScript + Tailwind CSS (один файл `index.html`).
*   **База данных:** Отсутствует (данные сессии хранятся во временной памяти).

## 📂 Структура проекта
```text
├── main.py          # Весь бэкенд: API, логика ИИ, обработка промптов
├── index.html       # Весь фронтенд: верстка, стили, логика чата и голоса
├── .env             # API-ключи (NVIDIA)
└── requirements.txt # Список необходимых библиотек
```

## 🚀 Этапы реализации (упрощенные)
1.  **Этап 1: Бэкенд и AI-ядро.** Настройка одного эндпоинта `/chat`, который принимает сообщение, историю и уровень, а возвращает ответ ИИ и разбор ошибок.
2.  **Этап 2: Веб-интерфейс.** Создание стильной страницы чата с использованием Tailwind CSS без использования сложных фреймворков.
3.  **Этап 3: Голос и Интеграция.** Подключение браузерного API для распознавания речи и озвучки текста.
4.  **Этап 4: Подготовка к защите.** Написание кратких комментариев к коду и инструкции по запуску.

## 🎓 Почему это решение идеально для защиты?
*   **Минимум файлов:** Нет путаницы в структуре.
*   **Никаких внешних зависимостей:** Не нужно настраивать PostgreSQL или Node.js.
*   **Прозрачность:** Каждая строчка кода имеет понятное назначение.
*   **Скорость:** Проект запускается за 2 секунды.
