 # AI Language Trainer 🇬🇧🗣️
    2
    3 **AI Language Trainer** — это интерактивная веб-платформа для
      практики разговорного английского языка с использованием мощностей
      современной языковой модели Llama 3.3.
    4
    5 ## 🌟 О проекте
    6
    7 Проект решает проблему "языкового барьера", предоставляя пользователю
      безопасную и бесконечно гибкую среду для тренировки. В отличие от
      большинства приложений с фиксированными уроками, здесь вы сами
      создаете контекст.
    8
    9 Интерфейс приложения полностью на русском языке, но погружение в
      языковую среду максимально строгое — после запуска сценария ИИ
      общается исключительно на английском.
   10
   11 ## ⚡ Ключевые возможности
   12
   13 - **Полная свобода сценариев:** Введите любую ситуацию текстом на
      русском языке (например: *"Я пытаюсь вернуть бракованный товар в
      магазине в Лондоне"*), и ИИ мгновенно подстроится под эту роль.
   14 - **Умная архитектура диалога (JSON):** ИИ одновременно генерирует
      ответную реплику и проводит анализ вашей грамматики. Результаты
      выводятся в отдельном окне.
   15 - **Голосовой движок (Web Speech API):**
   16   - ИИ озвучивает свои сообщения автоматически.
   17   - Вы отвечаете голосом в режиме рации (Push-to-Talk). Запись идет,
      пока кнопка зажата.
   18 - **Адаптация под уровень:** Выбирайте свой уровень (от A1 до C2) —
      ИИ будет использовать соответствующую лексику и грамматику.
   19 - **Оптимизированная память:** ИИ удерживает в контексте ровно 7
      последних реплик, что обеспечивает идеальный баланс между
      адекватностью диалога и скоростью ответа.
   20
   21 ## 🛠 Технологический стек
   22
   23 - **Frontend:** React + TypeScript + Vite
   24 - **Backend:** FastAPI (Python)
   25 - **AI:** NVIDIA NIM API (Llama-3.3-70b-instruct)
   26 - **Voice:** Браузерное Web Speech API
   27 - **База данных:** PostgreSQL
   28
