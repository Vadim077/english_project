# AI Language Trainer

**AI Language Trainer** — это интерактивная веб-платформа для практики разговорного английского языка с использованием мощностей современной языковой модели Llama 3.3.

## 🌟 О проекте

Проект решает проблему "языкового барьера", предоставляя пользователю безопасную и бесконечно гибкую среду для тренировки. В отличие от большинства приложений с фиксированными уроками, здесь вы сами создаете контекст.

Интерфейс приложения полностью на русском языке, но погружение в языковую среду максимально строгое — после запуска сценария ИИ общается исключительно на английском.

## ⚡ Ключевые возможности

- **Полная свобода сценариев:** Введите любую ситуацию текстом на русском языке (например: *"Я пытаюсь вернуть бракованный товар в магазине в Лондоне"*), и ИИ мгновенно подстроится под эту роль.
- **Умная архитектура диалога (JSON):** ИИ одновременно генерирует ответную реплику и проводит анализ вашей грамматики. Результаты выводятся в отдельном окне.
- **Голосовой движок (Web Speech API):**
  - ИИ озвучивает свои сообщения автоматически.
  - Вы отвечаете голосом в режиме рации (Push-to-Talk). Запись идет, пока кнопка зажата.
- **Адаптация под уровень:** Выбирайте свой уровень (от A1 до C2) — ИИ будет использовать соответствующую лексику и грамматику.
- **Оптимизированная память:** ИИ удерживает в контексте ровно 7 последних реплик, что обеспечивает идеальный баланс между адекватностью диалога и скоростью ответа.

## 🛠 Технологический стек

- **Frontend:** React + TypeScript + Vite
- **Backend:** FastAPI (Python)
- **AI:** NVIDIA NIM API (Llama-3.3-70b-instruct)
- **Voice:** Браузерное Web Speech API
- **База данных:** PostgreSQL
